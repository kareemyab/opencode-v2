# orgn Desktop

The orgn desktop app — a confidential agentic development environment built on Electron.

## Quick start

From the monorepo root:

```bash
bun install
bun run dev:desktop
```

From this package:

```bash
bun install
bun dev
```

## Brand constants

Single source of truth for user-visible identity:

```
packages/ui/src/brand/constants.ts
```

Import as `@opencode-ai/ui/brand`. Key exports:

| Constant | Example |
|---|---|
| `PRODUCT_NAME` | `orgn` |
| `APP_IDS` | `com.orgn.desktop.dev` / `.beta` / prod |
| `DEEP_LINK_SCHEME` | `orgn` |
| `UPDATE_PUBLISH_URLS` | DigitalOcean generic feed base URLs |
| `SUPPORT_URL` | `https://orgn.com/support` |

Runtime config paths stay on `opencode` (compat mode) — see `docs/contracts/orgn-desktop-v2-rebrand/DECISIONS.md`.

## Channels

Set via `OPENCODE_CHANNEL`:

| Channel | App ID | Updater |
|---|---|---|
| `dev` (default) | `com.orgn.desktop.dev` | Disabled |
| `beta` | `com.orgn.desktop.beta` | Generic feed |
| `prod` | `com.orgn.desktop` | Generic feed |

Override update feed at build time: `ORGN_UPDATE_URL`.

## Build & package

```bash
bun run build && bun run package
```

Platform-specific:

```bash
bun run package:mac
bun run package:win
bun run package:linux
```

Output lands in `dist/`. Linux `.desktop` and AppStream metadata are generated by `scripts/copy-metainfo.ts` during `prebuild`.
